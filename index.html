03 / Proof from real systems

Green is not the same as working.

These anonymised cases come from one documented production estate. The same failure modes we rescue shape how we design new systems.

Customer-path failure

Live commercial site down for four days

The API stayed healthy while every customer-facing page returned page-not-found.

DANGER: monitoring observed the endpoint, not the customer path.

Deployment integrity

Green deploy deleting production files

A successful upload mirrored a developer machine and silently removed files absent locally.

DANGER: success contained no source-of-truth or destructive-diff check.

Financial state

Payment received. Order lost.

A webhook acknowledged rejected and incomplete requests, so the provider stopped retrying.

DANGER: payment confirmation and recorded order state diverged.

Credential scope

One credential copied across 101 repositories

A write-capable credential propagated through configurations and tooling without an alert.

DANGER: one unnoticed secret crossed the entire estate.
